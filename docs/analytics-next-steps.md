# Analytics Next Steps

The site emits lightweight Microsoft Clarity events for case-study opens, the Biomode
brand-guidelines PDF, the View All Case Studies link, service-wing selection, and
contact-form start, success, and failure states. Events do not include form values or
other personal information.

TRIC Academy does not currently have an approved live-project URL in the public project
data. Once an official URL is approved, change its destination type to `liveWebsite` and
add the `tric_website_visited` event to that live link. Do not invent an external project
destination merely to collect the event.
